# Índice da documentação — UniCV

O **UniCV** é um player de videoaulas em formato SCORM 1.2 (Moodle) com vitrines Vimeo, progresso e temas, mais o **UniCV Studio**: painel para conectar Vimeo (OAuth), gerenciar vitrines, exportar HTML/SCORM/iframe e integrar via LTI 1.3 / xAPI.
